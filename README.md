# web

Sitio personal WR, publicado con GitHub Pages en https://wolfgangresendiz.github.io/web/

- `calculadoras/`: calculadoras de ingeniería hidráulica.
- `catalogo/`: catálogo privado de cotizaciones de piezas y servicios de agua potable. Requiere usuario y contraseña; los datos se publican cifrados y se administran con Claude (ver `CLAUDE.md`).

## Catálogo: comandos

```bash
npm run catalogo -- ayuda     # todos los comandos de gestión
npm test                      # pruebas
npm run capturas              # revisión visual con datos ficticios (Playwright)
```
